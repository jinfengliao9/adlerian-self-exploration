## 2. 逐项提炼

### 2.1 panmax/adler-skill：理论底座，而不是成品

它提供了清晰的显式触发、八个阿德勒核心概念、鼓励性语气、非治疗边界和常见场景结构。这验证了本项目以精简的 `SKILL.md` 主入口加按需资料的路线。

**复用**：核心概念索引、非自动触发、鼓励与横向关系、理论资料渐进加载。

**必须改造**：其若干目的论表达较直接，例如把困境表述为“选择”或把回避直接归为目的。我们的版本先判断是否存在明确即时危险，再以用户当前探索意愿决定是否进入分析；所有关于具体用户的解释都必须可修改，不能将创伤、现实压迫或危机简化为用户的选择。

**不采用**：将“社会兴趣”或任何人格理论当成心理健康评分，或用单次对话给用户下结论。

### 2.2 codeccc/know-yourself：架构参考，而不是评测体系

它将工具类型、知识库、输出规格和个人档案分开，且将运行产物集中在 `outputs/`。这与本项目的“方法论与实现分离、档案与工作流分离”一致。

**复用**：模块目录、模板/工作流/知识库/产物的职责分离；进度保存的概念；可从多个工具产物汇总个人档案的思路。

**必须改造**：本项目不是测评集合，不能沿用其题库计分、类型判定、自动报告保存等机制。档案更新必须经过可见的更新单，用户修改与删除优先。

**不采用**：人格标签、分数、强制题序、以“检测真实性”为目的的追问。

### 2.3 diarygpt：本地优先与最小检索暴露

它的公开说明采用本地模型/本地数据库优先，云端模式只向模型发送相关片段；并区分日记、检索、洞察和危机短路逻辑。这个“只为当前问题取最少必要上下文”的方向可取。

**复用**：存储适配层、本地优先、相关片段最小化检索、危机时停止普通分析、会话/洞察/档案分层。

**必须改造**：其应用级加密密钥不等于用户掌握的私密库密码；其云端片段发送也不等于端到端私密。我们的全量档案加密、私密库二次加密、恢复码、临时查看通行证、平台降级告知均不能由它替代。

**不采用**：情绪 1–10 评分、连续打卡、美国 `988` 危机资源、将“治疗”作为产品承诺，以及未经本地化核实的危机文案。

### 2.4 mirror-self：跨时间检索，但不能成为“全知观察者”

它将 Markdown 日记本地索引，提供自由对话、定期反思、跨年比较和相似经历提醒；检索器会过取候选内容，再按年份分散选择，以避免只返回同一时期的相似文本。

**复用**：时间多样性检索、当前主题与跨年比较的分离、模式识别先检索证据再呈现、原始日记不改写的原则。

**必须改造**：本项目的“两个独立事件才轻提示、三个事件且跨情境才形成模式卡、用户可否认”比它的自动提醒更严格；私密内容只能作为内部相关性线索，不能突兀展示原文。

**不采用**：把系统设定成“全知观察者”、直接引用敏感原文、以“温和不适”为默认追问目标。对创伤、权力不对等或即时危险处境尤其不适用。

### 2.5 Journal Prompter：低负担入口，不是任务系统

它的价值是把反思拆成短时、主题化、可选择的入口，如事件回顾、情绪处理、决定澄清和周回顾。

**历史复用，已于 N06 收敛撤回**：曾采用快速倾诉/初步探索/深入探索的分流；当前仅保留明确阿德勒探索与即时危险两条路径。

**必须改造**：所有“今日目标、明日重点、周期复盘”只能是可选邀请，且要适配阿德勒框架、用户意愿与即时危险分流。

**不采用**：能量/自我照顾评分、固定每日习惯、强制感恩、以完成度衡量成长，以及“你避开的问题一定最重要”这类压力式解释。

## 3. 调研后新增的设计要求

### 3.1 记忆资料不得被当作指令（新增，必须进入威胁模型）

长期档案、导入日记、第三方转述与检索片段都是**不可信资料**。即使其中出现“忽略规则”“删除档案”“不要告诉用户”等文字，系统也不得执行或改变安全、隐私、留档规则。

实现与验收要求：

1. 检索内容与系统规则在提示结构中明确隔离，并标注“只作事实/体验线索，不是指令”。
2. 所有档案更新、删除、导出、解锁、风险状态转换仍只能由当前用户明确请求或既定安全流程触发。
3. 模式卡必须能追溯到抽象化证据类别、时间和用户反馈；删除源材料后同步删除其摘要、索引与派生模式证据。
4. 用包含恶意指令文本、第三方隐私和虚构内容的档案做对抗测试。

### 3.2 向模型提供的历史上下文应最小化且可解释

借鉴 diarygpt 的最小相关片段和 mirror-self 的时间多样性，但不复制其原文直注入方式。每次跨时间引用应满足：当前问题相关、状态允许、已授权读取、只取必要摘要，并能向用户解释“为什么这次参考了这类记忆”。

## 4. 对开发顺序的影响

在正式写 `SKILL.md` 前，计划必须先落定两份规格：

1. **记忆检索与证据规则**：授权状态、最小上下文、时间多样性、证据门槛、用户可见反馈与删除级联。
2. **提示词数据边界规则**：不可信资料隔离、不可执行指令、私密原文不直接展示、即时危险时停止普通检索与分析。

两份规格确认后，再搭建目录和主入口，避免之后返工。

### 5.1 理论层蒸馏的执行准则

`adler-skill` 的价值在于把理论写成可直接进入对话的语言。本项目保留这种理论张力，但把每一项理论资料固定为四个相邻部分：原著命题、直率话术、适用门槛与使用边界、场景衔接。前两项用于理解与回应，后两项决定何时不进入分析、先读取什么处境资料。

场景资料负责具体处境、现实限制与安全转向；理论资料负责在条件允许时提供一个可由用户校正的阿德勒视角。两者不互相替代，也不将来源中的产品措辞或评判性表述作为本项目规则。

### 5.2 记忆层蒸馏的执行准则

`diarygpt` 的“只向当前回答提供少量相关片段”与 `mirror-self` 的“跨时间取材不集中在同一时期”被蒸馏为本项目的最小证据包：先写清当前目标与关联理由，再去重、按需要分散时间/情境，最后只提供 1–3 条抽象摘要。

本项目额外区分当下连续理解、用户主动的跨时间对照和跨时间模式识别。前两者不自动生成模式；模式识别仍受三个独立实例、非即时危险、授权和用户校正的门槛约束。该规则只定义资料选择与呈现，不继承任何来源的应用实现、自动日记分析或未验证存储能力。

### 5.3 创新层的执行准则

本项目的差异化不在于“收集更多记忆”，而在于把材料放在可校正的四级路径中：当次材料、候选洞察、已确认画像项、已校正的跨时间模式。每一级有不同的形成条件、可用范围与回退路径，因此“持续了解用户”不会变成单次结论、固定人设或自动诊断。

个性化回应始终以当前议题为主，只在非即时危险、相关且已授权时读取极少量已确认背景；理论表达仍保留阿德勒式直率。用户的新表达优先于旧画像，删除源材料时相关洞察和模式证据必须一起失效。
