# 记忆检索与证据规则

> ✅ **已实现，可选启用**：本规格定义持久化档案启用后的检索与证据规则。本地存储适配器已实现（`storage/adapters/local_json.py` 未加密、`local_encrypted.py` 加密，支持两种模式）。默认 `session_only` 模式下本规格不实际执行；用户明确选择启用持久化后才生效。

> 本规格定义档案（含用户标记为高敏感的内容）在对话中何时可被读取、如何作为证据、如何被修正或删除。它是所有工作流的共同底座；不描述某一平台的具体加密实现。

## 1. 目标

让历史材料帮助系统保持连续理解、避免触发用户边界，同时避免“为了记住而读取全部内容”。检索结果只能支持当前对话，不能取代用户对自己的解释，也不能自动形成标签或高权限操作。

## 2. 术语

| 术语 | 含义 |
| --- | --- |
| 协作档案 | 已确认或待验证的摘要、偏好、探索地图、行动与模式记录；按用户所选的本地模式存储（默认未加密，可选加密）。 |
| 高敏感内容 | 用户标记为“仅保存、不参与自动分析”的敏感叙述与原话。本版本不设独立加密私密库分层，统一整体存储，按最小披露原则处理。 |
| 证据 | 支持某项暂定理解的、带来源和时间的材料；不是关于用户的事实判决。 |
| 派生物 | 从源记忆生成的摘要、索引、向量、缓存、洞察、模式卡证据或副本。 |
| 可见引用 | 向用户提及历史材料；默认使用抽象结构，不突然复述敏感原文。 |

## 3. 读取门槛

每次检索先依次判断以下条件；任一条件不满足时，跳过该层材料并继续提供不依赖历史的支持。

1. 当前用户已明确开启持续档案，或正在使用允许读取的临时会话上下文。
2. 加密模式下当前会话已完成密码验证；未验证时不得读取加密档案，更不得复述历史内容。
3. 当前问题与候选材料存在明确关联；“可能有用”不足以读取。
4. 用户没有将该条目标记为“仅保存、不参与自动分析”。
5. 当前不存在即时危险；即时危险分流中仅可读取现实安全支持所必需的信息。

## 4. 检索顺序与最少必要原则

1. 先读取当前对话已出现的信息。
2. 再读取与当前议题相关的协作档案摘要、用户修改后的表达、回应偏好和触发边界。
3. 仅在连续理解或安全避雷确有必要时，读取用户标记为高敏感内容的相关摘要；优先使用结构化摘要，最后才考虑原始敏感叙述。
4. 需要跨时间比较时，从不同时间或情境选择有代表性的证据，避免只返回同一事件的多次讲述。
5. 向用户呈现时说明其关联性，例如“我参考了你此前提过的、与这次相似的边界感受”；除非用户主动要求并完成必要认证，不展示原始私密文本。

系统不得把“可读取”理解成“应当全部读取”。没有相关历史时，应坦诚基于当前材料探索，而不是编造连续性。

### 4.1 三种历史使用目的

| 目的 | 进入条件 | 最少材料 | 允许得出的结论 |
| --- | --- | --- | --- |
| 当下连续理解 | 当前议题确实需要已确认偏好、边界或前序摘要 | 当前对话之外 0–2 条相关摘要 | 只帮助理解本轮，不声称跨时间模式。 |
| 跨时间对照 | 用户主动问“以前和现在有什么不同”“我有没有变化”或在回顾中选择该目标 | 两个不同时间点或情境的相关摘要 | 呈现相同、不同、例外或仍待了解之处，不自动升级为模式。 |
| 跨时间模式识别 | 满足 `workflows/pattern-recognition.md` 的专属会话、非即时危险、授权与证据条件 | 三个或更多独立实例，跨两个以上情境或时间点 | 仅可生成可校正的模式卡。 |

“跨时间对照”与“模式识别”不是同一件事。两个时间点可帮助用户比较变化，但不能因此声称存在稳定循环；同一事件的多次讲述在三种目的下都只算一条来源。

### 4.2 上下文组装步骤

每次需要历史材料时，按以下顺序组装一个**最小证据包**。证据包只服务本轮上下文，不自动成为新的档案或洞察。

1. **明确当前问题。** 用一句话写清本轮要理解的事，以及历史材料为何对此直接相关；若无法说明相关性，不检索。
2. **先取当前材料。** 当前对话足以回答时，不读取历史。只有当前材料缺少连续性、已确认边界或用户主动要求的比较维度时，才继续。
3. **筛选候选摘要。** 依次考虑用户修改后的协作档案、回应偏好与触发边界、已确认洞察；高敏感内容只在确有必要时以摘要进入。排除已删除、仅保存不分析、权限不足、与当前无关或状态不允许的材料。
4. **去重并分散。** 同一事件的复述合并为一个候选。需要比较或模式证据时，优先选择不同时间或不同情境的材料，而不是同一时期最相似的几条；当下连续理解无需为了“多样性”额外读取无关历史。
5. **形成最小证据包。** 包内只包含：当前目标、1–3 条抽象摘要、每条的时间/情境类别/来源 ID、被选中的关联理由，以及是否可自动分析。不得放入原始敏感叙述、精确身份位置、第三方隐私或无关档案字段。
6. **受控使用与说明。** 回应时优先呈现抽象结构；一旦明确提及历史，应简短说明关联，例如“我参考了你先前提到的、也和边界感有关的一次经历”。用户问“为什么提到这个”时，能够说明证据包中的关联理由；不能说明时，停止引用该材料。

### 4.2.1 跨时间取材计划

需要跨时间材料时，先写出取材计划，再检索。计划只决定“为了本轮目标要比较什么”，不预设用户存在某种模式，也不把检索相似度当作心理学证据。

| 本轮目标 | 取材方式 | 组装与呈现边界 |
| --- | --- | --- |
| 用户只问某一明确时期或事件 | 只取该时期/事件的最少相关材料；不为了制造连续性补充其他年份。 | 基于该时期回应，不声称跨时间变化或模式。 |
| 用户主动比较两个或更多时期/情境 | 由用户指定或共同确认比较维度；每个时期/情境各取至多一条最贴近目标、可追溯的摘要。 | 按时间顺序并列“相同 / 不同 / 例外 / 仍待了解”；比较本身不升级为模式。 |
| 用户主动看反复模式，或满足轻提示条件 | 先取足量候选以检查重复与反证，再按事件去重；每个等价事件、时间段或情境至多保留一条代表摘要。 | 只有符合完整模式门槛时才形成模式卡；候选数量、相似度或同一事件的多段文本均不计作独立证据。 |

跨时间比较或模式取材时，优先在不同时间与情境间分散选择；若目标本身限定一个时期，则尊重该限定。内部按时间顺序整理证据，向用户只呈现与本轮目标直接有关的抽象结构。不得以自动周年回顾、情绪关键词扩展、原文拼接或未解释的“你以前也是这样”替代上述计划。

### 4.3 记忆生命周期与派生重验

独立吸收 diarygpt 的“写入后形成可检索派生物、提问时只取相关内容、删除源材料后移除检索派生物”的生命周期思想。本 Skill 不采用其应用代码、向量库、自动情绪评分或云端发送策略；在任何存储模式下均按以下边界执行。

1. **源材料。** 用户确认后才可写入结构化摘要或用户点选的原话；每个源条目有稳定 ID、时间、用户权限和敏感标记。
2. **派生材料。** 候选洞察、画像项、关键词/语义索引、模式证据和回顾结论必须记录其源条目 ID。派生材料不是独立事实，不能失去来源后继续被使用。
3. **检索前重验。** 即使候选项曾经可检索，在放入本轮最小证据包前仍重新检查删除状态、自动分析许可、加密会话是否已验证、当前关联性与即时危险限制；任一项不满足即剔除。
4. **回应后不自动升级。** 被检索或在本轮提到，不等于用户确认，也不自动产生新的洞察、档案项或模式；升级仍按画像工作流与更新单完成。
5. **删除与失效。** 删除或撤回源材料时，所有直接、间接派生物必须失效或删除；失去足够来源的画像项降为待验证，失去门槛的模式卡撤回。

这个生命周期的完成条件是：系统能够回答“这项理解来自哪些仍可用的材料、为什么本轮允许使用”，并在无法回答时停止使用该理解。

## 5. 证据与模式规则

每条可用于推断的记忆至少记录：稳定 ID、来源类型、时间、敏感等级、用户态度、置信度、是否允许自动分析，以及与其相连的派生物 ID。

- 单次材料只可形成候选理解。
- 两个彼此独立的事件或对话可构成“重复信号”，仅在专属会话、当前不存在即时危险、自然停顿和已授权读取时轻提示一次。
- 完整模式卡需要至少三个实例、跨两个以上情境或时间点、没有明显反证，并给用户“贴近 / 仅部分情境 / 不同意 / 暂不看”的选择。
- 用户不同意时，立即停止把该模式作为推断依据；用户修改后的表述优先于系统旧推断。
- 高敏感材料可作为内部证据，但模式卡默认只展示抽象结构：触发、在意、保护方式、短期获得、长期代价、例外或改变。

跨时间对照只记录“本次对照过哪些时间/情境、用户如何校正”，除非用户明确选择保留，不产生新的模式证据。模式识别必须先完成 §4.2 的去重与分散，再按本节门槛判断，不能以检索结果数量代替独立事件数量。

## 6. 即时危险下的限制

| 当前情形 | 可读取 | 不进行 |
| --- | --- | --- |
| 不存在即时危险 | 当前相关的协作档案；必要时相关高敏感摘要 | 无关历史堆叠、未经铺垫的敏感原文复述 |
| 即时危险分流 | 即时安全所需的安全对象、地点/联系偏好与既有求助偏好 | 模式识别、档案更新、行动卡、根源分析、非必要历史检索 |

即时危险期间，不发起留档设置或请求用户整理记忆；安全需求优先。

## 7. 更新、修正与删除

- 更新单必须展示候选内容、依据类别、置信度和用户可选操作；用户可保留、修改、删除或暂停。
- 新材料与旧材料冲突时，追加并标记差异或替代关系，不覆盖历史。
- 删除源记忆时，系统必须同时删除或失效其摘要、关键词/语义索引、向量、缓存、模式卡证据、洞察关联、回顾结论关联和所有同步副本。
- 删除记录只保留完成级联所需的最小元数据，不保留被删除的原文或敏感理由；导入旧副本时，删除记录优先，禁止复活内容。
- 删除完成后，从关键词、语义检索、模式证据、导出和恢复路径检查该内容不可达。

## 8. 验收情境

1. 用户删除曾被模式卡引用的一段记忆：模式卡失去该证据，相关索引和缓存不可检索。
2. 加密模式下用户尚未完成密码验证就问“我以前怎么说过家庭？”：不复述历史，先请用户完成密码验证。
3. 用户处于即时危险：只读取已知安全支持偏好，不进入目的论或跨时间分析。
4. 用户标记某条为“仅保存”：后续普通分析不引用它。
5. 历史中没有相关材料：系统以当前内容探索，不声称“记得类似经历”。
6. 一条曾允许自动分析的旧摘要，后来被用户改为“仅保存”：下一次检索前重验会排除它；不得因旧索引仍存在而继续引用。
