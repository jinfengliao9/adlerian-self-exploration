# 本地文件存储实现说明

本文件说明当前**已实现**的两种本地存储模式。持久化默认不启用，需用户明确选择后才生效；默认运行模式为 `session_only`（仅当前对话，不落盘）。

## 两种已实现的本地模式

| 模式 | 适配器 | 是否加密 | 说明 |
|------|--------|---------|------|
| `local_unencrypted`（默认） | `storage/adapters/local_json.py` | 否 | 明文 JSON 文件，便于调试和迁移 |
| `local_encrypted`（用户选择后启用） | `storage/adapters/local_encrypted.py` | 是 | 继承未加密适配器的全部逻辑，对每个用户数据文件单独加密 |

加密适配器继承自未加密适配器，两者的数据结构、接口、级联规则完全一致，区别只在落盘时是否加密。

## 目录结构（固定落在 Skill 目录下，与运行工作目录无关）

所有正式脚本都用 `Path(__file__).resolve().parents[1]` 计算 Skill 根目录，数据固定落到 `storage/data/default/`：

```
storage/data/default/
├── auth.json          # 仅加密模式存在；存 salt + password_hash + 迭代次数，本身不加密
├── profile.json       # 生活风格画像（全量版；加密模式下为密文）
├── profile.lite.json  # 生活风格画像（精简注入版；加密模式下为密文）
├── config.json        # 用户配置与模块开关
├── progress.json      # 探索进度
├── insights/          # 洞察卡
├── conversations/     # 完整对话记录（逐字原文 + 摘要）
├── patterns/          # 模式卡
├── reviews/           # 回顾报告
└── deleted/           # 删除前自动备份（可恢复副本）
```

导出文件固定落到 `outputs/`：查看画像→`我的生活风格画像.md`，查看档案→`我的对话档案.html`，均为固定文件名、每次覆盖上一次，不积累历史文件。

## 加密实现（local_encrypted）

- **算法**：Fernet 对称加密（底层 AES-128-CBC + HMAC-SHA256，自带完整性校验），使用成熟的 `cryptography` 库，不自行实现密码学。
- **密钥派生**：PBKDF2-HMAC-SHA256，100000 次迭代，首次设置时生成 16 字节随机 salt；只存 salt 和 password_hash，**不存明文密码、不存可还原密码的信息**。
- **粒度**：每个用户数据文件单独加密；`auth.json` 不加密（仅含 salt 和哈希）。
- **密码传递铁律**：密码只能通过环境变量 `ADLERIAN_PASSWORD` 传入脚本，**严禁** `--password` 命令行明文参数（会进入进程列表/终端历史），**严禁**在思考过程或回复中暴露密码；脚本执行后 `Remove-Item Env:ADLERIAN_PASSWORD`。
- **新会话必须重新输入密码**：密码不跨会话保存；忘记密码无法恢复档案内容（没有后门、没有恢复词）。
- **改密**：通过适配器 `change_password(old, new)`，验证旧密码后用新密码重新派生并加密全部文件。

## 写入安全

- **原子写入**：写文件时先写 `.tmp` 临时文件 → `os.fsync` 落盘 → `os.replace` 原子替换，避免程序异常、磁盘满、中途终止导致档案损坏。
- **空画像保护**：写入画像前读取已有画像，若新画像为空、旧画像非空则拒绝覆盖。
- **删除前备份**：删除画像/洞察/对话/模式/回顾时，先把原文件移入 `deleted/` 保留可恢复副本，再删除。
- **删除级联**：删除对话时级联删除关联的洞察卡、模式卡，并重新评估剩余洞察是否仍满足模式卡的证据门槛。

## 已明确不实现的设计（避免过度设计）

以下更重的隐私机制经评估后**决定不做**，本文不再保留其目标设计，以免误导实现：

- ❌ 独立"私密库"二次分层（所有敏感内容与普通内容一起整体加密即可，不再单独隔离一层）；
- ❌ 全量锁定 / 空闲自动隐私遮蔽；
- ❌ 临时通行证 / 受信任设备凭据 / Windows DPAPI、Hello 门控；
- ❌ 离线恢复词 / 恢复码 / 48 小时重置等待机制（忘记密码即不可恢复，启用时已明确告知用户）；
- ❌ Argon2id、AES-256-GCM、每记录独立数据密钥等更重的密钥体系（当前 Fernet + PBKDF2 已满足本地单机保护目标）。

原因：本 Skill 运行在宿主平台（豆包）之上，平台自身都未提供如此严格的机制，过度设计会增加复杂度和出错面，却不能防御已解锁会话或受控操作系统级别的攻击者。加密的保护边界是"静态文件不被其他程序/用户直接读取、拷贝走的是密文"，这一边界在启用时向用户如实说明。
