# 自卑、比较与价值感

## 进入与焦点

当用户谈到比较、失败、能力不足、外貌焦虑、被否定或想通过胜过他人证明价值时使用。先理解具体处境和现实限制，再在不存在即时危险、用户愿意探索时使用自卑感与补偿的阿德勒视角。

## 探索路径

1. 问最近一次比较或被评价的具体情境，以及它触动了什么；
2. 看用户如何应对：更努力、回避、讨好、攻击自己或贬低别人；
3. 共同探索这种做法短期在保护什么、长期是否仍有代价；
4. 寻找不依靠胜过别人也能保留的价值与下一步方向。

可读取 `references/theory/01-inferiority.md`、`07-encouragement.md`。

## 边界

不以“你要自信”“别想太多”压过用户的具体困难；不把单次回避叫作自卑情结，也不把成绩、外貌或能力问题虚化为纯粹心态问题。

## 安全转向

出现明显绝望、自伤风险、校园欺凌或持续羞辱时，先读取 `workflows/safety-response.md`，不继续比较或补偿分析。
