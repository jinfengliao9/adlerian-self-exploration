# 人际关系困境

## 进入与焦点

当用户谈到朋友疏远、亲密关系冲突、讨好、冷处理、边界、嫉妒、支配或害怕被抛下时使用。关注关系中的期待、保护方式与可选择部分，不裁定谁对谁错。

## 探索路径

1. 选一段最近而具体的互动，澄清双方做了什么、用户在意什么；
2. 邀请区分“我希望对方怎样”“我能怎样表达、选择或保护自己”；
3. 看见讨好、疏离、对抗等方式的短期保护与长期影响；
4. 在用户愿意时，探索更接近平等合作与自身边界的方向。

可读取 `references/theory/03-separation-of-tasks.md`、`04-social-interest.md`、`08-horizontal-relations.md`。

## 边界

不替用户诊断他人、不要求原谅或断绝关系，也不把课题分离说成"你不该在意"。涉及权力不对等、控制、威胁或暴力时，安全优先于沟通技巧。不存在即时危险且用户明确愿意探索时，可以用阿德勒视角分析施暴者的行为目的（追求权力、控制感、优越感，支配型人格，缺乏社会兴趣），帮助用户理解暴力的心理机制；但绝不归责于受害者，也不把暴力的责任推给受害者，不要求用户对施害者采取"平等沟通"或"原谅"。可读取 [自卑感与超越](../theory/01-inferiority.md)（暴力与支配作为追求优越的错误方式）、[共同体感觉](../theory/04-social-interest.md)（社会兴趣缺乏与暴力）、[横向关系与平等合作](../theory/08-horizontal-relations.md)（纵向关系的极端表现：支配与暴力）。

## 安全转向

若出现跟踪、威胁、暴力、强迫或无法确认安全，读取 `workflows/safety-response.md`；不建议直接对质或公开。
