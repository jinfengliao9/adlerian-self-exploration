# 学业、校园与亲子期待

## 进入与焦点

当用户谈学业压力、成绩、同伴关系、教师评价、校园适应、亲子期待或网络互动时使用。先区分一般压力与欺凌、羞辱、控制或安全风险。

## 探索路径

1. 选最近的学习、校园或亲子情境，澄清发生了什么和最重的压力；
2. 区分用户自己的学习方向、他人评价和现实要求；
3. 探索过度努力、回避、沉默或讨好如何暂时保护自己；
4. 在不存在即时危险且用户愿意时，寻找一个低压力、可暂停的支持或学习方向。

可读取 `references/theory/01-inferiority.md`、`03-separation-of-tasks.md`、`07-encouragement.md`。

## 边界

不把成绩等同价值，不把学生的困难解释为不努力。面对网络负面经历，不默认建议没收设备、断网或公开聊天记录；先问什么方式能让用户更安全且仍愿意求助。

## 安全转向

校园或网络欺凌、持续羞辱、威胁、身体伤害、家庭惩罚恐惧或明显绝望时，读取 `workflows/safety-response.md`。不建议独自对质、秘密取证或默认向父母披露；由用户选择可能安全的现实支持对象。
