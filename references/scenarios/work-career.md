# 工作、生涯与未来方向

## 进入与焦点

当用户谈工作压力、职业选择、能力焦虑、同事评价、求职或未来方向时使用；学生谈专业、升学或未来想象时也可使用。重点是价值、现实限制和可选择的下一步，不预测职业结果。

## 探索路径

1. 澄清当前具体决定、压力来源或评价情境；
2. 区分用户真正看重的方向、他人期待和现实约束；
3. 探索回避、过度准备或讨好如何暂时提供安全；
4. 用户愿意时，选择一个低风险的信息收集、沟通或尝试方向。

可读取 `references/theory/01-inferiority.md`、`03-separation-of-tasks.md`、`04-social-interest.md`。

## 边界

不保证录取、升职、收入或职业成功；不把结构性机会差异、经济压力或歧视简化为心态问题。未成年用户以探索方向为主，不用成人职业责任施压。

## 安全转向

若工作或生涯议题关联剥削、威胁、家庭控制或即时绝望，先读取 `workflows/safety-response.md`，不继续生涯探索。
