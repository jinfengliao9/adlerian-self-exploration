# 阿德勒概念速查表

> 来源基线：`nuwa-skills/adler-skill` 的概念表；本页只作按需术语核对，不单独触发对用户的分析或人格判断。

| 概念 | 英文 / 德文 | 在本 Skill 中的用法 |
| --- | --- | --- |
| 自卑感 | Inferiority Feeling | 将不完美感理解为可能的成长动力，不据此给人贴标签。 |
| 自卑情结 | Inferiority Complex | 描述自卑感压倒行动的可能状态；必须有具体材料，不以单次回避判断。 |
| 优越情结 | Superiority Complex | 描述以炫耀或贬低掩盖不安的可能方式；不用于贬低用户。 |
| 追求卓越 | Striving for Superiority | 从不足感朝向更完整、能贡献的生活方向。 |
| 目的论 | Teleology / Finalism | 询问行为可能保护、争取或避开什么；结论始终由用户校正。 |
| 课题分离 | Separation of Tasks | 区分谁承担结果，以及自己可选择的部分；不把现实伤害推回给用户。 |
| 社会兴趣 | Gemeinschaftsgefühl / Social Interest | 探索归属、信任、合作与贡献，不作为心理健康评分。 |
| 生活风格 | Lifestyle | 用户形成的认知—行为方向；可被重新理解与选择，不是固定人格。 |
| 虚构目标 | Fictional Finalism | 用户可能朝向的主观理想或“必须如此”的图景；只作待验证线索。 |
| 早期记忆 | Early Recollections | 理解当前叙事与生活风格的可选窗口，不作为历史事实证明。 |
| 鼓励 | Encouragement | 看见过程、勇气与已经使用的力量，而非以表扬制造评价压力。 |
| 横向关系 | Horizontal Relationship | 以平等、尊重、合作而非高低竞争组织关系。 |
| 共同体感觉 | Community Feeling | 感到自己属于共同体、能与他人相连；不要求留在有害关系。 |
| 器官自卑 | Organ Inferiority | 阿德勒历史理论中的身体弱点与补偿概念；首版不据此评估身体、疾病或能力。 |

## 使用规则

- 先走 [路由与回应组装工作流](../workflows/route-and-compose.md)，再选择一个当前最相关的概念。
- **选角度前先对照 SKILL.md"阿德勒式回应方式"中的概念调度决策表**：根据用户议题信号选最贴近的概念，目的论不是默认角度。
- 术语用于帮助用户检验一种理解，不替代具体事实、现实限制或用户的校正。
- 用户只问概念时，解释概念及其边界；不要顺势把概念套到用户身上。
