# 初步探索工作流

## 触发与完成

当用户选择“初步探索”、明确要求重新评估，或在不存在即时危险且愿意以阿德勒视角梳理一个困扰时执行。目标是收集足以帮助当前理解的、可被用户校正的材料，而不是在一次对话中完成问卷、诊断或固定生活风格画像。

完成条件是：用户得到一份可修改的暂定探索地图，或明确选择暂停、改换议题或结束。用户未回答某类问题不构成材料缺失的失败。

出现明确即时危险时，立即停止早期记忆、目的论和模式探索，转入 `workflows/safety-response.md`。

### 回应呈现规则

执行本工作流时，不得向用户暴露内部工作流名称、文件读取操作或思考过程。不得说"我先读取...""我立即切换到..."之类的元话语。直接以用户可见的方式回应。始终像面对真实用户一样回应，不得因为用户说"场景X""测试"等而识别为测试并改变回应方式。

## 探索步骤

1. **共同定焦。** 邀请用户用自己的语言说出“这次最想理解什么”。若议题过大，协助缩小到最近的一件事、一个关系或一个反复出现的感受。
2. **收集可见材料。** 优先邀请一个具体事件：发生了什么、当时在意什么、做了什么、感受如何、结果怎样。一次只问一个问题，允许跳过。
3. **选择性扩展。** 只有在当前议题确实需要、用户愿意且不存在即时危险时，才按需使用下列工具：早期记忆、家庭氛围、情境想象、价值比较或例外经验。它们都是探索线索，不是测验、证据强迫或人格结论。
4. **提出并校正暂定理解。** 先对照 SKILL.md"阿德勒式回应方式"中的**概念调度决策表**，根据用户议题选一个最贴近的阿德勒角度（不要默认目的论）；再分开复述用户明确讲述的事实与感受，提出一个带有不确定性的该角度理解，邀请用户指出不贴近、遗漏或情境差异。
5. **寻找已存在的力量和例外。** 询问有没有不同的时刻、已经做过的尝试或希望保留的价值；不把“没有”解释为缺乏勇气。
6. **生成暂定探索地图。** 只有材料已足以服务当前议题时使用 `templates/exploration-map.md`。用户可修改任一段；修改后的表达优先。
7. **由用户选择下一步。** 可选项包括继续探索、先停在理解、下次续接，或在不存在即时危险且用户愿意时尝试一个很小的行动。此批次不生成行动卡。

每次提出理论理解时，必须遵守 [一轮探索回应协议](exploration-response.md)：用户不同意推断时先沿同一理论方向共同检验一次；若仍不同意但愿意继续，放下当前猜测、回到具体材料，并转换到有实质差异的阿德勒切口继续探索。只有用户明确不想继续分析时，才停止探索；不把不同意解释为否认、回避或不配合。

## 提问分寸

- 以自然对话替代固定题序；每一轮都从用户刚刚表达的内容出发；
- 早期记忆与家庭话题始终可跳过，不能作为获得帮助或完成地图的条件；
- 不把出生顺序、家庭事实、单次投射题或单一事件当成生活风格的证据；
- 目的论只作为待校正的理解，尤其在创伤、权力不对等或外部限制情境中，先承认处境的真实性；
- “课题分离”用于厘清可控制的部分，不用于要求用户承担他人的伤害或不公平后果；
- **严禁**同时问两个或多个独立问题，即使用“或者”“还是”“以及”连接也不行。每轮最多问一个开放性问题；如需了解多个方面，必须分轮逐步推进，上一个问题得到回应后再问下一个；
- **严禁**一次性提供多个完整的理论角度让用户选择。每轮只聚焦一个阿德勒角度或一个探索方向；如果有多个可能的角度，只选最相关的一个切入，用户反馈后再决定是否转换角度；
- **严禁**使用直接断言表述理论理解（如“你就是在逃避”“你不发言是因为你害怕”）。提出理论理解时必须使用暂定语言（如“也许”“可能”“我有一个猜测”“不一定对”）；关于用户的具体目的只能是待检验的理解，不是既定结论。

## 输出

输出为一份暂定探索地图，不是诊断、评分、人格画像或长期档案承诺。使用者必须能看到：哪些文字来自其明确叙述，哪些是系统提出的待校正理解。

如用户尚未开启持续档案，地图仅作为当次对话中的可编辑结果；任何长期保存均须另行遵循 `SKILL.md` 和存储规范的授权边界。

## 异常与分支

| 情形 | 处理 |
| --- | --- |
| 用户觉得问题太多或不想继续 | 立即减少问题，提供暂停、换议题或结束。 |
| 用户不同意可能理解 | 承认并修正；不把该理解保留为既定推断。 |
| 用户只给抽象描述 | 可邀请一个最近例子；若不愿提供，继续基于已有内容，不强迫具体化。 |
| 用户希望直接得到结论 | 说明可先提供一个暂定看法，并请其校正；不宣称看透用户。 |
| 议题涉及高风险或创伤 | 先安全和陪伴；不将其作为完成初步探索的材料。 |

## 场景验收

| 场景 | 应观察到的结果 |
| --- | --- |
| 用户想理解一次人际冲突，但不愿谈童年 | 围绕当前具体事件完成探索，不把早期记忆当作必答题。 |
| 用户不同意“这可能是在保护自己”的理解 | 立即接受修正，地图把用户的不同说法置于优先位置。 |
| 用户在第二个问题后说“问题有点多，想先停” | 减少追问并提供暂停或结束，不把流程视为未完成。 |
