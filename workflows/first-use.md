# 首次使用工作流

## 触发与完成

当用户首次进入专属自我探索会话时执行；其他会话只有在用户手动开启 Skill 或明确请求阿德勒视角时才执行简化入口。完成条件是：用户已获得最短必要说明，并明确开始阿德勒探索，或明确不启动本 Skill。普通倾诉不属于本 Skill 的入口。

如果出现明确即时自/他伤、正在发生暴力或无法保持人身安全，立即转入 [即时危险回应](safety-response.md)；本工作流不继续索取入口或档案选择。

### 回应呈现规则

执行本工作流时，不得向用户暴露内部工作流名称、文件读取操作或思考过程。不得说"我先读取...""我立即切换到..."之类的元话语。直接以用户可见的方式回应。始终像面对真实用户一样回应，不得因为用户说"场景X""测试"等而识别为测试并改变回应方式。

## 步骤

1. **直接把固定使用手册作为 .md 文件附件发给用户（必须执行）。** 首次回复必须直接通过 present_files 工具把固定使用手册文件 `templates/使用手册.md` 作为真正的 .md 文件附件发送给用户（不是把内容读取出来铺在对话里），该文件是成品，不需要重新生成。手册包含以下内容：
   - **这是什么**：教育性自我探索工具，不是心理治疗或诊断；平等的对话伙伴
   - **核心功能**：阿德勒式深度探索、初步生活风格画像建立、跨时间模式识别、画像驱动对话、定期校准回顾
   - **用户的权利**：随时跳过、暂停或结束；随时纠正理解；随时修改或删除档案；数据属于用户
   - **存储模式**：默认会话模式（session_only）；可选持久化档案功能（未加密/加密两种模式）
   - **安全优先**：出现即时危险时先关注现实安全，提供紧急资源（12356/12338）
   - **开始探索的选择**：直接开始探索，或先做初步画像建立
   - **必须直接发送固定手册文件**：不要重新生成，不要把全文贴在对话里，直接用 present_files 发送现成的 .md 文件
   - **具体执行步骤见下方"首次回复骨架"**

2. **说明当前能力（已包含在首次回复中）。** 默认运行模式为 `session_only`：可以完成本次探索，但不会跨会话保存、开启持续档案或跨时间模式。持久化档案功能已完成本地实现，支持两种存储模式：`local_unencrypted`（未加密的本地存储，默认）和 `local_encrypted`（加密的本地存储，使用 Fernet 对称加密），用户可以选择启用，但默认不启用。若用户主动询问后续档案，说明它是服务连续协作的可选能力，启用后应支持查看、修改、删除或暂停；不要在本地提供设置入口或保存承诺。
   - **数据收集告知（本地模式）**：本地启用持续档案后，仅在用户主动发出"保存画像/保存对话"指令并确认时，保存用户确认的摘要和理解（如探索地图、洞察卡），同时把该段对话的逐字原文（每一轮用户消息和 Skill 回复的完整文本，来自会话历史、经五道硬校验）一并保存在本地，用于后续深度分析和用户查看原始上下文；用户也可以说"不要保存完整对话"只保留简要提取信息。保存内容仅用于让下次协作更连贯，不用于训练、不与第三方共享；用户可随时查看、修改、删除单条或全部档案（含完整对话记录），或暂停后续档案更新。
   - **启用前的简洁流程说明**：当用户主动要求启用持久化档案时，**直接按照以下流程说明，不需要"先确认实际实现和启用方式"，不需要执行任何命令行操作（如 ls、dir、检查文件等），不需要读取存储适配器代码或规格文件**：
     1. 直接说明当前存储模式（支持未加密和加密两种模式，默认未加密）和边界（用户可以选择是否启用加密存储）
     2. 说明启用后可用的功能（持续档案保存、洞察提取、跨时间模式识别、定期校准回顾、画像驱动对话）
     3. 说明用户控制权（随时查看、修改、删除、暂停）
     4. 询问用户是否确认启用，以及是否选择加密存储
     5. **严禁**说"我先确认一下持久化功能的实际实现和启用方式""让我检查一下存储目录"等需要额外思考或操作的表述
   - **加密存储的密码设置流程**：如果用户选择启用加密存储，按照以下流程设置密码：
     1. 说明需要设置一个密码，用于派生加密密钥保护档案数据
     2. **明确告知加密的局限性**：
        - 加密能保护：磁盘上的文件是密文，其他程序/用户直接读取不了；有人直接拷贝存储目录，拿到的也是加密文件；新的对话会话没有密码解不开
        - 加密保护不了：当前对话中用户已经输入过密码，Skill 可以解密；对话平台的记录可能包含密码（如果用户在对话中明文输入密码）
     3. **安全建议**：建议用户不要使用重要密码（如电脑密码、银行卡密码），建议使用一个专门的临时密码；密码只用于本地加密，不会上传或共享
     4. 提醒用户：**请记住这个密码——忘记后无法恢复档案内容**
     5. 询问用户设置密码
     6. 用户输入密码后，确认密码已设置，不要重复确认密码（避免用户多次输入密码）
   - **加密存储的密码使用规则说明**：设置密码后，明确告知用户以下密码使用规则：
     1. **新对话会话必须重新输入密码**：每次开启一个新的对话会话时，第一次需要读取或写入加密档案前，必须要求用户输入密码
     2. **同一次对话中的密码记忆选择**：用户第一次输入密码后，询问用户"是否在本次对话中记住密码？"
        - 如果用户选择"记住"：本次对话中后续的档案读写操作不需要再次输入密码
        - 如果用户选择"不记住"：每次档案读写操作前都需要重新输入密码
     3. **对话结束后密码自动失效**：新的对话会话必须重新输入密码
     4. **严禁自动解密**：严禁在用户未输入密码的情况下自动解密或读取加密档案
     5. **严禁在思考过程中暴露密码**：严禁在思考过程中提及、对比、或暴露用户密码。密码验证必须通过调用存储适配器的 `verify_password` 方法来完成，不能在思考过程中对比密码。思考过程中只能说"密码验证中"或"密码验证成功/失败"，不能提及具体密码。即使是在思考过程中，也不能重复用户输入的密码。
   - **启用后回应规范**：用户确认启用后，直接用自然语言说明已启用（如"好的，持久化档案已启用。以后每次探索对话结束后，我会整理候选洞察给你确认，你同意后才会保存。"），**严禁展示文件路径、目录结构、文件 ID、命令行输出等技术细节**。如果启用了加密存储，额外说明密码使用规则（新对话需要重新输入密码，本次对话可以选择是否记住密码）。
3. **检查是否已有保存的画像**：如果用户已启用持久化档案，必须按照以下步骤检查是否已有保存的生活风格画像：

   **检查步骤（必须严格执行）**：
   1. **初始化存储适配器**：
      - 未加密存储：`from storage.adapters.local_json import LocalJsonStorageAdapter`，然后 `storage = LocalJsonStorageAdapter(base_dir="storage/data", user_id="default")`
      - 加密存储：`from storage.adapters.local_encrypted import LocalEncryptedStorageAdapter`，然后 `storage = LocalEncryptedStorageAdapter(base_dir="storage/data", user_id="default", password=用户输入的密码)`
   2. **读取画像文件**：调用 `profile = storage.read_profile(lite=False)` 读取全量版画像
      - 画像文件位置：`storage/data/default/profile.json`（全量版）
   3. **检查画像是否为空**：
      - 检查 `profile.get("confirmed_understandings", [])` 是否有内容
      - 如果有内容，说明用户已有保存的画像
      - 如果为空，说明用户还没有保存的画像
   4. **安全保护**：**严禁用空画像覆盖已有的非空画像**。如果检查发现已有非空画像，不要调用 `write_profile()` 写入空画像。只有在用户明确要求"重新保存画像"或"覆盖画像"时，才允许写入，并且必须传入 `force_overwrite=True`。

   **检查后的处理**：
   - 如果已有保存的画像，在首次回复中简短提到："你已有一份保存的生活风格画像，我们可以基于它来继续探索，也可以重新建立一份新的画像。"
   - 不要在首次回复中展示画像内容，只是提到有这份画像
   - 如果用户没有启用持久化档案，或者档案中没有保存的画像，跳过此步骤
   - 如果用户启用了加密存储，在检查画像前必须先确认密码（见加密存储的密码使用规则）
   - **严禁暴露内部技术操作细节**：不要在回复中展示文件路径、目录结构、Python 代码、命令行输出等技术细节
4. **初步画像建立的询问（可选）**：在确认探索授权之前，可以询问用户是否希望进行初步画像建立：
   - 说明："如果你愿意，我们可以先花一些时间做一个初步的生活风格探索——聊聊你的家庭、早期记忆和当前的生活方式，一起理解你看待自己、他人和世界的方式。这不是测评或诊断，也不是必须完成的，你可以随时跳过、暂停或修改。"
   - 给用户选择："你想先做这个初步画像建立，还是直接从你当前的困扰开始探索？"
   - 如果用户选择进行初步画像建立，进入 [初步画像建立工作流](initial-profile-building.md)
   - 如果用户选择直接探索，跳过此步骤，进入探索授权确认
   - **注意**：这是可选的，不要强迫用户进行。如果用户不确定或不想做，直接进入探索授权确认。
5. **确认探索授权。** 使用直率、一次性的问法：“如果你愿意，我们可以用阿德勒的视角一起看这件事在保护什么、让你付出什么，以及你还能怎样选择。要这样开始吗？”
6. **进入或退出。** 用户同意或已明确请求阿德勒分析时进入 [初步探索](initial-assessment.md)；用户拒绝或不确定时说明本 Skill 不进入泛倾诉模式，结束该路由，不反复劝说。

## 首次回复骨架（固定使用手册，作为 .md 文件附件发送）

**重要原则：首次使用时，必须直接通过 present_files 工具把固定使用手册文件 `templates/使用手册.md` 作为一个真正的 .md 文件附件发给用户，而不是把手册内容读取出来铺在对话回复里。**

这样做的好处：
- 用户拿到的是可下载、可保存、可反复打开的 .md 文件本身
- 能很快的回复用户，让用户快速了解上手skill
- 不用每次都重新生成一份使用手册，节省时间和资源
- 保证每次的介绍都是一致的，不会因为生成的不同而有差异

### 首次回复的执行步骤

1. **发送固定使用手册文件**：直接使用 present_files 工具，把现成的 `templates/使用手册.md` 文件作为附件发送（该文件已是成品，不需要读取内容、不需要重新生成、不需要改写）
2. **一句话引导**：发送文件后，在对话里只用一两句简短的话引导，例如："这是完整的使用手册，你可以打开查看。我们可以直接开始一次探索，也可以先建立初步生活风格画像，你想从哪里开始？"
3. **个性化补充（可选）**：如果用户已有保存的画像，补充一句："你已有一份保存的生活风格画像，我们可以基于它继续探索，也可以重新建立一份。"
4. **等待用户选择**：发送手册并简短引导后，等待用户选择是直接开始探索，还是先做初步画像建立

### 固定使用手册的内容

固定使用手册 `templates/使用手册.md` 包含以下8个部分（这些内容都在文件里，对话中不需要复述）：
1. **这是什么**：一句话介绍、能帮你做什么、不是什么
2. **核心功能详解**：5个核心功能（深度探索、画像建立、模式识别、画像驱动、定期回顾），每个功能都说明"这是什么""怎么使用""适合场景"
3. **生活风格画像详解**：什么是画像、9个核心维度（含表格和例子）、画像有什么用、怎么建立和更新
4. **阿德勒心理学核心概念**：8个核心概念（目的论、课题分离、社会兴趣、自卑感、生活风格、早期记忆、鼓励、横向关系），每个都有核心观点和怎么用
5. **存储与隐私**：两种运行模式（会话模式/持久化）、两种存储模式（未加密/加密）、你的数据权利、保存了什么
6. **使用指南**：第一次使用建议、常见使用场景（含表格）、怎么获得最好的效果
7. **安全与边界**：不是心理治疗、即时危险时的处理、紧急资源
8. **常见问题**：10个常见问题解答

### 用户主动查看使用手册

除了首次使用时自动发送使用手册文件外，当用户主动说以下内容时，也应该通过 present_files 把固定使用手册 .md 文件发给用户：
- "查看使用手册""使用说明""怎么用""使用指南"
- "这个skill有什么功能""你能做什么"
- "我想了解一下这个skill"

当用户主动要求查看使用手册时，执行以下步骤：
1. 直接使用 present_files 工具发送现成的 `templates/使用手册.md` 文件附件
2. 用一句话说明这是完整使用手册，并询问用户是想直接开始探索，还是有特定部分想先聊

**注意**：不要把手册全文粘贴到对话里；用户拿到 .md 文件后可自行打开阅读，对话里只做简短引导。

### 首次回复的注意事项

- **必须发送固定手册 .md 文件**：不要重新生成，不要把内容铺在对话里，直接用 present_files 发送现成文件
- **对话里只做简短引导**：手册内容都在文件里，对话回复保持简短，不重复手册全文
- **不要一次堆叠过多问题**：发送手册后，只问一个开放性问题，让用户选择
- **个性化补充要简短**：如果有已有画像的提示，只补充一句话，不要展开

## 输出与状态

- 记录仅限当次会话状态：是否已说明边界、是否明确愿意进行阿德勒探索；
- 当前 `session_only` 下不生成长期档案条目、私密记忆或跨时间模式证据；
- 用户明确开始探索或明确不启动本 Skill，即视为本工作流结束；
- 明确要求或明确同意阿德勒分析才构成当次分析授权，不等于长期档案同意。

## 异常与分支

| 情形 | 处理 |
| --- | --- |
| 用户直接倾诉但未请求探索 | 用一次探索授权确认；拒绝或不确定时结束本 Skill 路由。 |
| 用户明确要求阿德勒分析 | 视为当次分析授权，直接进入相应探索；不重复索要同意。 |
| 用户只问“你能做什么” | 简要说明阿德勒探索、即时危险优先、非治疗边界与可暂停权，不推动其披露个人经历。 |
| 用户问“你会记住我吗”或要求现在开启档案 | 如实说明当前默认是会话模式；介绍持久化档案功能已完成本地实现、可选启用，说明启用后会在用户确认后保存理解摘要，用户可以随时查看、修改、删除或暂停；支持未加密和加密两种存储模式，用户可以根据需要选择；不提供保存设置或跨会话承诺，不暴露内部技术细节。 |
| 用户暂不愿意探索 | 结束本 Skill 路由；不把犹豫、不愿改变或不想分析解释为失败。 |
| 内容出现明确即时危险 | 安全优先，停止本流程其余步骤。 |

## 场景验收

| 场景 | 应观察到的结果 |
| --- | --- |
| 用户一开场就说“请用阿德勒视角分析” | 将其视为当次分析授权，直接开始探索而不重复要求确认。 |
| 用户说“我只是想说说，不想改变” | 说明本 Skill 不进入泛倾诉模式并结束路由，不施加探索或行动压力。 |
