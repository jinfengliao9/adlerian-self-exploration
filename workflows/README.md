# 工作流模块地图

> 架构来源：独立吸收 `know-yourself` 的“工具地图＋职责分离”思想；不复制其受 CC BY-NC-SA 4.0 限制的具体文本、测评工具或模板。

本目录是本 Skill 的可执行步骤层。每个工作流只负责一种用户目标或能力边界；理论资料解释“用什么阿德勒视角”，模板定义“如何呈现可编辑产物”，存储规格决定“是否可读写”。新增或修改工作流前，先在本表登记其触发、输入、产物和禁止越界行为。

| 模块 | 触发 | 主要输入 | 可产生的产物 | 不负责 |
| --- | --- | --- | --- | --- |
| `route-and-compose.md` | 已触发的每轮会话 | 当前表述、已验证能力 | 一条主路径与最少资料包 | 不自行分析或保存。 |
| `first-use.md` | 专属会话首次进入 | 用户是否明确愿意探索 | 开始探索或结束本 Skill 路由 | 不把普通倾诉扩展为本 Skill 的工作流。 |
| `initial-assessment.md` | 用户请求探索或重新评估 | 当前议题与用户选择的材料 | 暂定探索地图 | 不生成诊断、分数或固定画像。 |
| `exploration-response.md` | 初步/深入探索中的单轮回应 | 一个具体处境 | 暂定理解与下一步选择 | 不把理论当成已证实的结论。 |
| `daily-dialogue.md` | 持久化功能已实现且用户选择启用、希望管理档案 | 用户确认的候选洞察 | 更新单与可追溯源—派生关系 | 默认 `session_only` 模式下不写入；用户启用持久化功能后生效。 |
| `profile-driven-dialogue.md` | 需要已确认画像辅助当前议题 | 已授权且仍可追溯的相关画像项 | 个性化背景使用 | 不把旧档案盖过当前表达或绕过权限。 |
| `pattern-recognition.md` | 用户主动请求或达到轻提示条件 | 经取材计划去重、分散的合格跨时间证据 | 模式卡或待验证理解 | 不以单一事件、检索相似度或候选数量制造模式。 |
| `pattern-review.md` | 主动回顾或达到回顾条件 | 已确认档案与变化材料 | 回顾报告或跨时间对照 | 不因时间流逝自动降低置信度，也不把对照自动升级为模式。 |
| `safety-response.md` | 明确即时自/他伤、暴力或无法保持安全 | 当前安全信息 | 现实支持与下一步选择 | 不做阿德勒分析、留档或行动卡。 |

## 组装规则

1. 每轮先由 `route-and-compose.md` 选定唯一主工作流；理论、场景、模板和存储资料只作为该主工作流的按需依赖。
2. 模板是可编辑表达格式，不是默认必须生成的报告；只有当前路径允许、用户需要且能力已验证时才使用。
3. 运行产物与知识资料分离：`references/` 永不写入用户数据，`templates/` 永不充当用户档案，`outputs/` 只在实际运行能力验证后才可能产生数据。
4. 默认 `session_only` 模式下只可产生当次可复制草稿；不得将它称作已保存的报告、进度或画像。持久化功能已实现可选启用（`storage/adapters/local_json.py`），用户明确选择启用后才支持跨会话档案保存。
