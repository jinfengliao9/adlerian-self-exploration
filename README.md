# 阿德勒式自我探索 Skill

一个以阿尔弗雷德·阿德勒个体心理学为框架的教育性、自我探索型对话 Skill。它希望在平等、温和而直率的对话中，帮助使用者梳理当下困扰、理解反复出现的思维—行为循环，并在本人愿意时尝试小而可撤回的行动。

## 项目定位

本项目想做的是一面有记忆边界、可被使用者校正的“结构化镜子”，而不是替人下结论的权威。

- 关注目的论、课题分离、鼓励、社会兴趣、生活风格与横向关系等阿德勒核心概念；
- 只在用户明确愿意时进入阿德勒探索；即时危险时优先现实安全支持；
- 长期方向是基于用户可见、可修改、可删除的档案，谨慎呈现跨时间的重复模式；
- 不收集年龄，也不按年龄分层；只有用户明确愿意探索时才进入阿德勒分析，明确即时危险时则优先现实安全支持。

它不是心理治疗、临床诊断、危机干预替代品，也不应被当作通用聊天机器人或人格判定工具。遇到可能的自伤、自杀、对他人的即时伤害、失去人身安全等情形，安全确认、现实支持与紧急求助优先于任何阿德勒式分析。

## 当前状态

本项目以 GitHub 为开源仓库。使用者将本仓库 clone 到自己电脑上豆包工作的技能目录，即可在本地豆包工作中加载使用。本仓库已具备主入口、工作流、理论按需资料、模板、示例、隐私边界与文档治理规则。

### 当前默认模式：`session_only`

默认运行模式为 `session_only`：可使用明确授权后的阿德勒探索与即时危险回应；上下文只限当前对话。不会默认开启跨会话档案、私密库、自动长期记忆、跨时间模式识别或任何加密承诺。

### 持久化功能（已实现，可选启用）

持久化档案功能已完成本地实现（`storage/adapters/local_json.py`），当前存储模式为 `local_unencrypted`（未加密的本地存储，高敏感内容建议不保存）。用户可以选择启用持久化功能，启用后支持：

- 持续档案保存与跨会话记忆（生活风格画像，全量版+精简注入版双档案设计）
- 日常对话洞察提取与档案更新（每次对话提炼洞察候选，用户确认后写入）
- 画像驱动对话（基于生活风格画像提供个性化回应）
- 跨时间模式识别（基于持久化档案识别重复模式，至少3个独立实例）
- 定期校准回顾（10次对话或1个月后邀请回顾）
- 用户配置管理（4个模块开关，用户可随时启用/禁用）
- 探索进度保存（长时间对话支持中断后恢复）

**默认不启用**，需要用户明确选择后才生效。本地模式下，用户主动保存并确认后，保存用户明确确认的摘要和理解，同时把该段对话的逐字原文（每一轮用户消息和 Skill 回复的完整文本，来自会话历史、经五道硬校验）一并保存在本地，用于后续深度分析和查看原始上下文；用户也可以说"不要保存完整对话"只保存简要提取信息。

### 不做的能力

独立"私密库"二次分层、全量锁定、访问通行期、恢复码等重机制经评估已决定**不实现**（改用整体加密覆盖，避免过度设计）；未启用的能力不显示为当前可依赖功能。

## 使用边界

阿德勒式探索只在以下情形进入：

- 用户进入专属自我探索会话；
- 用户手动开启本 Skill；
- 用户明确请求以阿德勒视角分析。

在其他工作或普通聊天中不默认分析。表达是否想探索不明确时，只进行一次确认；普通倾诉不属于本 Skill 的工作流。

对话中形成的理解应始终使用“可能”“也许”“需要你校正”等暂定语言。用户对自己的修改优先于系统推断；不使用人格标签、道德评判、完成打卡或把未行动解释为失败。

## 隐私与档案原则

持续档案的目的，是让后续协作更连贯，而不是为了收集而收集。持久化功能已完成本地实现，**默认不启用**，需要用户明确选择后才生效。启用后，档案中的候选洞察必须让用户看见、修改、删除或暂停留存，原始逐字对话不应在未经用户选择时自动转入长期档案。

用户拥有自己的档案数据所有权。Skill 不会将用户的档案数据出售、出租或共享给任何第三方；不会将用户对话内容或档案数据用于训练 AI 模型。用户可以随时查看、修改、删除单条或全部档案，或暂停后续档案更新。

本地存储支持两种模式：`local_unencrypted`（未加密，默认）和 `local_encrypted`（Fernet 整体加密，用户明确选择后启用）。本版本不设独立私密库分层、不做全量锁定；未加密模式下高敏感内容建议不保存。

仓库中的 `outputs/` 仅用于运行时用户数据，已由 `.gitignore` 排除，不应提交。实际存储、检索与加密能力须以所在平台经过验证的能力为准；若平台无法做到承诺的保护，应降级处理或明确告知，不得虚假保证。
